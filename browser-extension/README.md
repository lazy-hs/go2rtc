# go2rtc 浏览器扩展

这是 go2rtc 的便携控制端，界面沿用当前 Web 控制台的深色与青色视觉体系。点击扩展图标会打开一个完整的独立页面，而不是容易被授权窗口关闭的工具栏弹窗。扩展本身不包含后端，也不复制播放器实现；它连接用户本机或局域网中正在运行的 go2rtc，并用原生 Web 页面播放视频流。

## 能力

- 添加多个本机、局域网或带 `api.base_path` 的 go2rtc 服务端，并随时切换
- 在侧栏查看各服务端的在线、离线或待授权状态
- 按目标协议和主机申请站点权限，不在安装时索取全部站点访问权；Chrome 的权限模式不区分端口
- 支持可选的 HTTP Basic Auth
- 合并已配置任务和实时连接状态，停用任务也会显示
- 查看视频流、源数量和观看者数量
- 通过 `/api/streams/state` 启停单路任务
- 来源列仅展示本地视频文件名或去除认证信息后的上游 RTSP 地址
- 一键打开 Web 控制台和播放器，并复制当前服务端发布的 RTSP 流地址
- 无 npm 依赖、无需构建

## 安装

### Chrome / Edge

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录 `browser-extension/`。

### Firefox（临时调试）

1. 打开 `about:debugging#/runtime/this-firefox`。
2. 选择“临时载入附加组件”。
3. 选择本目录中的 `manifest.json`。

安装或更新后，点击工具栏中的扩展图标会打开 `dashboard.html` 完整页面。添加 go2rtc 的 Web 地址，例如：

```text
http://localhost:1984
http://192.168.1.20:1984
https://camera.example.com/rtc
```

保存时扩展会先把服务端配置写入本地存储，再打开 Chrome 站点权限确认窗口。授权窗口不会关闭控制台页面，授权成功后会直接连接并加载视频流。

从 `0.1.x` 版本升级时，旧版的单服务端地址、用户名、密码和未完成授权状态会在首次打开新页面时自动迁移为服务端列表，无需重新填写。

## FFmpeg 与本地运行边界

浏览器扩展受安全沙箱限制，不能直接启动用户电脑上的 `ffmpeg` 或 go2rtc 可执行文件。当前形态采用以下分工：

```text
浏览器扩展 -> go2rtc HTTP/WebSocket API -> 用户本机 PATH 中的 FFmpeg
```

因此用户需要先在本机运行 go2rtc，并确保 `ffmpeg` 可从运行 go2rtc 的环境变量 `PATH` 中找到。go2rtc 原有的 FFmpeg 检测、拉流和转码逻辑不需要为扩展重复实现。

如果未来需要“点击扩展图标自动启动本地 go2rtc/FFmpeg”，必须增加一个单独安装的 Native Messaging 本地伴随程序；这不属于纯浏览器扩展能够安全完成的能力。

## 安全说明

- 扩展只在用户保存连接配置时申请目标 origin 的访问权限。
- 用户名和密码保存在扩展的本地存储中，不会使用同步存储。
- 建议局域网外访问时启用 HTTPS 和 HTTP Basic Auth。
- go2rtc API 包含摄像头与配置管理能力，不应直接暴露到不受信任的公网环境。
